# What I practiced
Built a single real Bash script, onboarding.sh, from scratch, piece by
piece: shebang, a name prompt, a config file existence check, a loop
pinging three real servers, a command-substitution-based connectivity
check with numeric comparisons, and a while loop counter — testing the
script at each stage before adding the next piece, rather than writing
it all at once.

# What surprised me
This was the first day where everything came together into one
genuinely reusable piece of automation, rather than a sequence of
one-off commands typed interactively. Running ./onboarding.sh and
watching it prompt, check, loop, and report back felt like a real shift
from "operating Linux" to "programming Linux."
