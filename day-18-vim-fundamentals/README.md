# What I practiced

Today's practice drill involved opening a new file in vim, typing three lines of text, saving it, reopening it, deleting the middle line, undoing that deletion, and finally saving and quitting. I learned the basic workflow of creating and editing a file in vim, including switching between insert mode and command mode, saving changes, and using undo to restore deleted content.

# What surprised me

I was surprised that vim opens in command mode by default—I expected to be able to type immediately like a regular text editor. I also learned that forgetting the colon before commands like `:w` results in nothing happening, which was an easy mistake to make at first.
