# Day 1 – Where Am I? Basic Orientation

## Commands Learned

- pwd → Shows current working directory
- ls → Lists files and directories
- ls -l → Displays detailed file information
- ls -a → Shows hidden files
- ls -la → Detailed list including hidden files
- ls -lh → Long format with human-readable file sizes
- cd /var/log → Navigate using absolute path
- cd .. → Move one directory up
- cd ~ → Go to home directory
- cd - → Return to previous directory

## Practice

- Printed working directory using `pwd`
- Navigated to `/var/log` using absolute path
- Returned to home directory using `cd ~`
- Switched back using `cd -`
- Listed directory contents using `ls -lh`

## Notes

- Absolute paths start from root (`/`)
- `~` represents the home directory
- `cd -` is useful to quickly switch between two directories
- `ls -lh` improves readability of file sizes
