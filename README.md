# 30-Day Linux Command Mastery Challenge

I’ve decided to spend the next 30 days getting much more comfortable with Linux.

The goal is simple: learn and actually use **300 Linux commands and their derivatives**, instead of just knowing what they mean on paper. I’ll be working through file navigation, permissions, users and groups, package management, environment variables, text processing, processes and services, networking, Bash scripting, and SSH.

Every day, I’ll practice the commands on a real Linux system, document what I learn in my Command Journal, commit my work to GitHub, and share a short update on LinkedIn.

This is less about memorising commands and more about getting to the point where using Linux starts to feel natural.
