# Commands - Day 2

## mkdir
Creates a new, empty directory.

## mkdir -p
Creates a directory along with any missing parent directories in one command.

## touch
Creates a new empty file, or updates its timestamp if it already exists.

## cp
Copies a single file to a new location or name, leaving the original untouched.

## cp -r
Copies a directory and everything inside it, recursively.

## mv
Moves a file/directory to a new location, or renames it if staying in the same folder.

## rm
Deletes a single file permanently, with no trash/recycle bin.

## rm -r
Deletes a directory and everything inside it recursively.

## rm -rf
Force-deletes a directory and its contents without confirmation — the most dangerous common Linux command if used carelessly.

## rmdir
Deletes a directory, but only if it is completely empty — refuses otherwise, making it a safer deletion tool.
